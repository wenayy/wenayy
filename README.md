## About me

I like building software where product, backend, infrastructure and AI meet, and I care most about whether people
end up using it. I've shipped a Chrome extension used in 20+ countries, an AI clipping pipeline whose clips have
crossed 3M+ views, native Mac apps, and an internal platform a startup's founding team used every day.

I want to understand how the whole system works, not just one layer of it: agents and LLM workflows, APIs and queues,
real-time systems, media pipelines, deployment, and the performance and failure modes underneath.
